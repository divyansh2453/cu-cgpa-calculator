## 🧮 How SGPA is Calculated

```
SGPA = Σ (Grade Points × Credits) / Σ Credits
```

**Example:**
| Subject | Grade | Credits | Grade Points |
|---------|-------|---------|--------------|
| Maths   | A+ (10) | 5     | 50           |
| Physics | A  (9)  | 4     | 36           |
| English | B+ (8)  | 3     | 24           |
| **Total** |     | **12**  | **110**      |

```
SGPA = 110 / 12 = 9.17
```

---

## 🧮 How CGPA is Calculated

```
CGPA = Σ (SGPA of all semesters) / Number of Semesters
```
